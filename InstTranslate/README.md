# InstTranslate

Webページ上のテキストを選択した時点で、Chrome 右上に翻訳を出す拡張機能です。

先に Chrome 内蔵の端末内翻訳を使い、使えない環境だけ Google 翻訳の公式ページを開きます。アカウント作成や API キーは不要です。

## 読み込み方法

Chrome（または Edge）の最新安定版を使います。ローカル翻訳は Chrome 138 以降のデスクトップ向けです。

1. このフォルダを手元に置く
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** をオンにする
4. **パッケージ化されていない拡張機能を読み込む** をクリックする
5. このリポジトリのフォルダ（`manifest.json` がある場所）を選ぶ
6. InstTranslate が表示されれば読み込み完了

Edge の場合は `edge://extensions` で同じ操作です。

ツールバーにアイコンが見えないときは、パズル型の拡張機能メニューから InstTranslate をピン留めしてください。

## 設定方法

設定画面は、ツールバーの InstTranslate アイコンをクリックすると開きます。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 即時翻訳 | オン | オフにすると、テキストを選んでも翻訳しない |
| 選択解除後も残す | オフ | オンにすると、選択を外しても翻訳パネルが残る。× か Esc で閉じる |
| 翻訳元 | 自動判別 | 自動で言語を見るか、特定の言語に固定するか |
| 翻訳先 | 日本語 | 右上パネルと Google 翻訳の両方で使う翻訳先 |

設定は Chrome の同期ストレージに保存されます。同じ Google アカウントで Chrome にログインしている別端末へも反映されます。

Google アカウントへのログインは、この拡張機能の利用自体には不要です。

## 使い方

1. 外国語の Web ページを開く
2. 分からない箇所をマウスで選択する（ダブルクリックや Shift + 矢印でも可）
3. 画面右上に翻訳が出る
4. 初期設定では選択を外すと右上パネルはすぐ消える。「選択解除後も残す」をオンにすると残る。Esc か × でも閉じる

右上パネルは訳文だけを出す。原文や「端末内で翻訳」などのラベルは出さない。訳文の量に合わせて大きさが変わる。

「初回モデル準備中」が出るのは、次のときだけです。

- 翻訳元が自動判別で、言語検出モデルをまだ端末に入れていない
- その言語ペア（例: 英語 → 日本語）の翻訳モデルをまだ端末に入れていない
- 翻訳元や翻訳先を変え、まだダウンロードしていない組み合わせを初めて使う

一度入ったモデルは Chrome が端末に残す。同じ組み合わせなら、次からは準備中は出ない。

入力欄（`input` / `textarea` / 編集可能な領域）での選択、1文字だけの選択、空白だけの選択では開きません。

初回だけ、Chrome が言語モデルをダウンロードすることがあります。右上に進捗が出ます。

## 動かないとき

- コードを更新したあとは `chrome://extensions` で InstTranslate の再読み込みを押し、開いていたタブも再読み込みする
- `chrome://`、Chrome ウェブストア、一部の PDF では動作しない
- 設定の「即時翻訳」がオンか確認する
- アイコンに `OFF` バッジが出ているときは無効状態
- 右上に出ず Google 翻訳窓だけ開く場合は、その環境で Chrome 内蔵翻訳が使えない

## 使わないもの

- 自前サーバーの翻訳 API
- Google の非公式翻訳エンドポイント
- 拡張機能に翻訳モデル一式を同梱すること
