================================================================================
  SoftMap ユーザーマニュアル
================================================================================

PCのソフト環境とフォルダ構成を、軽量なスナップショットとして記録するツールです。
ファイルの中身はバックアップしません。
「何のソフトがあったか」「どんなフォルダ構成だったか」を後から確認するためのものです。


--------------------------------------------------------------------------------
1. はじめに
--------------------------------------------------------------------------------

  必要なもの
    - softmap.exe（単体で動作。インストール不要）
    - 任意: softmap.conf

  設定ファイルの探索順
    1. -c / --config で指定したパス
    2. softmap.exe と同じフォルダの softmap.conf
    3. カレントディレクトリの softmap.conf

  権限
    - 一般ユーザーで可（管理者不要）

  しないこと
    - ファイル本体のバックアップ
    - ソフトの自動インストール
    - レジストリ／OS設定の復元

  ライセンス・免責

    - 無保証（AS IS）。詳細は DISCLAIMER.txt
    - 本ソフトの利用は自己責任です


--------------------------------------------------------------------------------
1.1 プライバシー（重要）
--------------------------------------------------------------------------------

  スナップショットにはホスト名・ソフト一覧・フルパスが含まれます。
  実機スキャン結果（.smb / .smap）を公開リポジトリや共有フォルダに
  置かないでください。


--------------------------------------------------------------------------------
1.2 デフォルトのスキャン範囲
--------------------------------------------------------------------------------

  対象
    - 接続中の固定ドライブ（自動検出。C: 決めつけなし）

  対象外（デフォルト）
    - USB 等のリムーバブル、CD/DVD、ネットワークドライブ
    - 明示するとき: --drive E:\

  各ドライブ内
    - ルートから均一に再帰走査
    - 除外: Windows, $Recycle.Bin, pagefile.sys, .git 等


--------------------------------------------------------------------------------
2. PowerShell での実行（重要）
--------------------------------------------------------------------------------

  PowerShell では、カレントの exe を呼ぶとき「.\」が必要です。

    NG:  softmap -h
    OK:  .\softmap.exe -h

  例: exe があるフォルダへ移動してから実行

    cd C:\path\to\SoftMap\build\Release
    .\softmap.exe -h
    .\softmap.exe scan -o snapshot.smb
    .\softmap.exe report snapshot.smb


--------------------------------------------------------------------------------
3. 基本機能（BF）の意味
--------------------------------------------------------------------------------

  BF = 基本機能の番号です。

    BF1  OS認識ソフトの記録
         → Windows レジストリ（Uninstall）にあるソフト
         → 見るとき: report --software

    BF2  ドライブ全体の記録
         → フォルダ名・ファイル名の地図（中身は保存しない）
         → 見るとき: report --tools / --tree

    BF3  記録の保存
         → scan で .smb または .smap に保存

    BF4  記録の参照
         → report / info

    BF5  復元支援
         → report --checklist / restore

  ソフト全体 = BF1（レジストリ） + BF2（ツール系の補完）


--------------------------------------------------------------------------------
4. コマンド一覧
--------------------------------------------------------------------------------

  全体ヘルプ

    .\softmap.exe -h

  サブコマンド

    scan      走査してスナップショットを作る
    report    スナップショットを表示する
    info      件数などのメタ情報だけ表示
    restore   フォルダ構造だけ空で再現する

  共通オプション（先頭に付ける）

    -h, --help       ヘルプ
    -v, --verbose    詳細ログ
    -q, --quiet      エラーのみ


--------------------------------------------------------------------------------
5. 普段の使い方（これだけでよい）
--------------------------------------------------------------------------------

    .\softmap.exe scan -o snapshot.smb
    .\softmap.exe report snapshot.smb

  1つ目で記録、2つ目で短いサマリー表示です。


--------------------------------------------------------------------------------
6. scan（走査・保存）
--------------------------------------------------------------------------------

  書式

    .\softmap.exe scan [options]

  主なオプション

    -o, --output <file>   出力ファイル（例: snapshot.smb）
    -c, --config <file>   設定ファイル
    --software-only       レジストリのみ（BF1のみ）
    --light               軽量走査（folders_and_apps）
    --drive <path>        走査ドライブ上書き（例: E:\）。省略時は固定ドライブ自動検出

  出力形式

    snapshot.smb     バイナリ（通常はこちら）
    snapshot.smap   テキスト形式のスナップショット

  例

    .\softmap.exe scan -o snapshot.smb
    .\softmap.exe scan -o snapshot.smb -c softmap.conf
    .\softmap.exe scan -o light.smb --light
    .\softmap.exe scan -o soft.smb --software-only
    .\softmap.exe scan -o d_only.smb --drive D:\


--------------------------------------------------------------------------------
7. report（参照）
--------------------------------------------------------------------------------

  書式

    .\softmap.exe report <snapshot> [options]

  ※ <snapshot> は必須です（パスを省略するとエラーになります）

    NG:  .\softmap.exe report
    OK:  .\softmap.exe report snapshot.smb

  オプションなし → 短いサマリーのみ

    .\softmap.exe report snapshot.smb

  詳細を見る（オプトイン）

    --software     BF1: レジストリのソフト一覧
    --tools        BF2: exe / lnk のツール一覧
    --checklist    再セットアップ用チェックリスト
    --tree         フォルダ／ファイルの木
    --depth N      --tree の深さ（省略時は 3）
    -O, --output   レポートをファイルへ書き出す
                   （大文字のオー。数字のゼロではない）

  例

    .\softmap.exe report snapshot.smb --software
    .\softmap.exe report snapshot.smb --tools
    .\softmap.exe report snapshot.smb --checklist
    .\softmap.exe report snapshot.smb --tree --depth 5
    .\softmap.exe report snapshot.smb --tree --depth 99 -O tree.txt

  「全体」に近い見方（ファイルへ出力推奨）

    .\softmap.exe report snapshot.smb --software --tools --tree --depth 99 -O full.txt

  注意: -o（小文字）は scan 用、-O（大文字）は report 用です。


--------------------------------------------------------------------------------
8. info（メタ情報）
--------------------------------------------------------------------------------

    .\softmap.exe info snapshot.smb

  ホスト名、走査日時、ソフト件数、ノード／ディレクトリ／ファイル件数などを表示します。


--------------------------------------------------------------------------------
9. restore（フォルダ構造の再現）
--------------------------------------------------------------------------------

  何をするか
    - スナップショットに記録された「ディレクトリ」を --target 配下に作る
    - 空フォルダの再現のみ

  何をしないか
    - ファイル中身の復元
    - ソフトの再インストール

  書式

    .\softmap.exe restore <snapshot> --target DIR [options]

  オプション

    --target DIR     復元先（必須）
    --dry-run        実際には作らず予定だけ表示
    --dirs-only      ディレクトリのみ（デフォルト動作）
    --map old=new    パス置換
    -y, --yes        確認プロンプトをスキップ

  例

    .\softmap.exe restore snapshot.smb --target D:\Restored\ --dry-run
    .\softmap.exe restore snapshot.smb --target D:\Restored\
    .\softmap.exe restore snapshot.smb --target D:\Restored\ -y
    .\softmap.exe restore snapshot.smb --target D:\Restored\ --map C:\=D:\Restored\


--------------------------------------------------------------------------------
10. テキスト出力のやり方
--------------------------------------------------------------------------------

  A) レポートをテキストファイルへ（よく使う）

    .\softmap.exe report snapshot.smb -O report.txt
    .\softmap.exe report snapshot.smb --software -O software.txt

  B) スナップショット自体をテキスト形式で保存

    .\softmap.exe scan -o snapshot.smap
    .\softmap.exe report snapshot.smap


--------------------------------------------------------------------------------
11. 設定ファイル（任意）
--------------------------------------------------------------------------------

  ファイル名: softmap.conf
  無くても組み込みデフォルトで動作します。
  探索順: -c 指定 → exe と同じフォルダ → カレントディレクトリ

  主な項目（例）

    [tree]
    ; drives 省略時は接続中の固定ドライブを自動検出
    ; drives = auto
    ; drives = E:\
    ; exclude は組み込みデフォルトに追加（置き換えではない）
    exclude = MyTemp
    depth = all_files          ; または folders_and_apps

  指定して使う

    .\softmap.exe scan -o snapshot.smb -c softmap.conf


--------------------------------------------------------------------------------
12. ビルド（開発者向け要約）
--------------------------------------------------------------------------------

  Visual Studio 2022 がある場合:

    「x64 Native Tools Command Prompt for VS 2022」を開く

    cd <SoftMapのフォルダ>
    cmake -B build -G "Visual Studio 17 2022" -A x64
    cmake --build build --config Release

  出力

    build\Release\softmap.exe

  詳細は BUILD.md を参照。


--------------------------------------------------------------------------------
13. よくあるつまずき
--------------------------------------------------------------------------------

  Q. softmap が認識されない
  A. PowerShell では .\softmap.exe と書く。

  Q. report requires snapshot path
  A. スナップショットのパスが無い。例: report snapshot.smb

  Q. ダブルクリックするとすぐ閉じる
  A. 引数なし起動のため。コンソール単体起動時は Enter 待ちになる。
     普段は PowerShell / cmd からコマンド付きで実行する。

  Q. -O と -o の違い
  A. -o = scan の保存先 / -O = report の書き出し先

  Q. --software にポータブルアプリが出ない
  A. レジストリに無いため。--tools または --tree を使う。


--------------------------------------------------------------------------------
14. クイックリファレンス
--------------------------------------------------------------------------------

  記録する
    .\softmap.exe scan -o snapshot.smb

  概要を見る
    .\softmap.exe report snapshot.smb

  ソフト一覧（レジストリ）
    .\softmap.exe report snapshot.smb --software

  ツール一覧（exe/lnk）
    .\softmap.exe report snapshot.smb --tools

  ツリーを深く見る
    .\softmap.exe report snapshot.smb --tree --depth 99 -O tree.txt

  チェックリスト
    .\softmap.exe report snapshot.smb --checklist

  件数確認
    .\softmap.exe info snapshot.smb

  フォルダだけ再現（確認）
    .\softmap.exe restore snapshot.smb --target D:\Restored\ --dry-run
